crt-rack \u00b7 live demo

Your site, but it's rack gear.

The exact rack from bryanhamilton.info, running on GitHub Pages. Bottom rail: \u23FB power cycle, EST VFD clock, the DJ Calendar ticker, scroll position in dB, real LCP/CLS. Press \u2318K / Ctrl+K for the palette.

Hover the ticker

Hover a DJ name: the dock opens with their photo and next show, and a 30-second iTunes preview starts playing through the 8-bar analyser EQ. Move away and it stops. This is the same bh-eq.js player that runs in production \u2014 live iTunes lookups, Web Audio API, no audio files.

The ticker

Production feeds the rail from a PHP endpoint with the live top-10 leaderboard. GitHub Pages can't run PHP, so the demo ships that exact payload inline \u2014 same names, photos, dates, and format. One fetch swap when self-hosted.

Scroll me

The dB readout tracks your position. Real PerformanceObserver numbers in the HUD \u2014 not fake ones.

Zero dependencies

One CSS file, one JS file. No framework, no build step, no analytics. Reduced motion? The EQ canvas steps aside.

Palette eggs: ls, whoami, rm -rf / \u00b7 and the console knows the old code.
