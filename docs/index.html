crt-rack \u00b7 live demo

Your site, but it's rack gear.

Everything on this page is the rack. Bottom rail: VFD clock, the DJ Calendar top-5 ticker (same five, same format as production), scroll position in dB, real LCP/CLS from your browser. Press \u2318K / Ctrl+K for the command palette. Hit the \u23FB power button bottom-left for the full CRT shutdown-and-reboot - with sound.

The ticker

Production serves it live from a 40-line PHP proxy with a 30-minute cache. GitHub Pages can't run PHP, so the demo ships the identical five items inline - #1 DAVID GUETTA through #5 ARMIN VAN BUUREN, trailing-space spacing and all. Swap one fetch for the real thing when you deploy it.

Scroll me

The dB readout tracks your position. Real PerformanceObserver numbers in the HUD - not fake ones.

Zero dependencies

One CSS file, one JS file, ~13KB combined. No framework, no build step, no analytics.

Graceful everywhere

Reduced motion? The CRT animation steps aside. Mobile? The HUD hides, the rail stays. Audio arms on your first click - the way browsers - and good manners - demand.
